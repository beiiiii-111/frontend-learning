# 前端工程化学习仓库

> 用于前端工程化学习练习，记录学习过程与代码。

## 项目介绍

本仓库用于系统学习前端工程化知识：Git 版本管理、npm 包管理、Vite 构建工具，以及 Vue3 基础语法练习。

## 技术栈

- **Git** — 版本控制
- **npm** — 包管理
- **Vite** — 构建工具 / 开发服务器
- **Vue 3** — 组合式 API（`<script setup>`）

## 目录结构

```
frontend-learning
├── 01-vue-literal      # 练习1：不借助构建工具，CDN 引入 Vue3（字面量方式）
├── 02-vite-vue-demo    # 练习2：Vite 脚手架创建的标准 Vue3 工程
└── README.md
```
