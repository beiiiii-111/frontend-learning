## 为什么先写这个

这个页面刻意绕开了构建工具：`createApp` 直接传一个带 `data` / `methods` 的配置对象，浏览器加载完就能跑。
它存在的意义是当对照组 —— 后面单元 2 用 Vite 搭工程时，能直观看出「有构建」和「没构建」差在哪：

| 维度 | 字面量写法（本目录） | 工程化写法（单元 2 起） |
| --- | --- | --- |
| 引入 Vue | CDN `<script>`，全局 `Vue` 对象 | `npm install vue` + `import` |
| 组件写法 | 配置对象写在一个 HTML 里 | 每个组件一个 `.vue` 文件 |
| 模板 | 写在 HTML 里，靠浏览器解析 | 由编译器预编译成渲染函数 |
| 样式 | 全局 `<style>` | `<style scoped>` 局部作用域 |
| 依赖管理 | 手动维护 CDN 地址和版本 | 锁文件锁定整棵依赖树 |
| 上线 | 直接丢 HTML | 构建压缩、分包、加 hash |
